## v7

v7 = v6 + the program-path rewrite (branch harness/v7, commits b467087 and 85b3a78). It combines:

- **From the generator review (G1–G4):**
  - one decided reply per twin group, read by the later rewordings;
  - "after the change" means now, with every change applied;
  - before → after lines;
  - value hygiene (action without timing, contact as the listed handle).
- **From DrPresident v20, released:** same-minute copies shown once (`once_each`) and a notes-only state reading
  (here the ledger call), with an A → B → C worked example in the closing note.
- **Ours:**
  - `LEDGER_RULES`, general rules for reading change records;
  - the shared ledger, keyed on the notes alone, so all four members over the same notes share one.

**Assistant turns.** The ledger and the earlier reply go in as assistant turns (85b3a78). The causal
answer_in_prompt gate (`scoregates/causal_dependence.go`, shadow today) counts value tokens of
harness-written system/user text as harness-first, but tests assistant-role spans against every completion of
the session. Both the ledger and the earlier reply are completions, so carried as assistant turns they read as
model-derived. Quoted inside the user turn, a reply whose value is not word for word in the records (a date
written out, a list rejoined) would flag. The first user turn still holds the notes and a message, because
ActCheck and RepeatAuthorization read `messages[1]`.

**Rule line:** the model writes every reply. The host never compares, retries, overwrites or ships an earlier
reply. This is the 2026-10-29 precedent `october-29-reused-draft-no-disagree-clause`.
