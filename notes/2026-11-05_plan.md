## Cost to under $1 (and ≤ $0.50 for v17)

1. Tool selector on every call that sends the catalog: the largest single cut.
2. Cheap routes (evidence view, short and topic paths, same-question reuse): already in both bases.
3. Effort set per call: low for retrieval-like calls (model card effort table).
4. Lean records engine (drafts and follow-up off, 1 search pass) only where code sees an easy case; test it
   on the base's full-engine cases.
5. For v17: one deciding call with code doing the routine work (approach 1 in the papers digest); dan0l v41's
   design shows it can be done at 0.99.
