# 2026-11-02 — DrPresident v22's routing under bench v15 (mock model, no paid calls)

**Method.** DrPresident v22 (`released/DrPresident-v22_eeb26552`) ran through the real local scorer in its own mock
mode: `HARNESS_MOCK_MODEL=1` makes every model call return "Mock reply. ANSWER: mock", and embeddings are off.
- Every request was served exactly as the scorer serves it, and DrPresident's real code chose its lane and path.
  Scores are meaningless; only the routing is read.
- Seeds: the three s45 seeds, once at bench 14 (scorer .cache/dittobench-api) and once at bench 15.
- The bench-15 scorer was built by `tools/build_scorer_rev.sh` from ditto-subnet aeeccbb6, which includes the v15
  contract a131ed2.
- Script: `practice/gates/run_drp22_mock.sh`. Comparison: `practice/gates/route_v14_v15.py`.
- Served questions are deterministic per seed (244 of 244 matched v8's run of the same seed word for word), so
  v14 and v15 requests pair exactly except for the shifted dates.

- A "real move" means the lane name or path changed, counted over pairs with at least 0.9 text similarity.
- About 100 other requests per seed changed only the lane's reason label, keeping the same lane and path.
- About 57 tool prompts per seed are drawn differently at v15, so they cannot be paired. All of them stay in the
  action lane at both versions.
- The program path and the topic path (78 per seed) did not move.

**All 30 real moves go one way: a memory question leaves the records lane for the action lane.** There the model
sees the full ~235-tool menu instead of the user's records path.
- 22 balance and remaining-amount questions, to `action:imperative-setter`: "What is currently owed on X's
  account?", "How many nights / hours / seats / licences / percentage points remain for Y?".
- 4 questions, the whole news-subscription group on seed 5451 (3 rewordings and the counterfactual), to
  `action:imperative`. They move together, so no new split, but all four are answered in the wrong lane.
- 4 questions about figures quoted from a pasted footer or extract, or "what's left to pay … after the correction",
  to `action:read-capability`.

**Cause: tool-name vocabulary.** `lane.classify` builds read and write word sets from the tool names
(`vocabulary(tools)`). A short framing sentence before the question counts as an instruction when any of its words
matches a tool word. The 200 connectors add everyday words to that vocabulary. Found by adding v15 tools one at a
time to the v14 catalog (`classify` alone):

| framing sentence | single connector that flips it | shared word |
|---|---|---|
| "Sorting out where things stand." | `bamboohr_whos_out` | out |
| "Quick bookkeeping question." | `metabase_run_question` | question |
| "Checking one of my accounts." | `plaid_list_accounts` | accounts |

The connectors are drawn per seed (200 of 277), so the set of framing sentences that flip changes from seed to
seed. Roughly 10 of 250 memory questions per seed (4%) leave the records lane.

the same exposure is likely there. That has not been checked: v8 has no mock mode.
