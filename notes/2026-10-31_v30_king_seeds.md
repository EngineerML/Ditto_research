## Candidate changes (general, model-side; none tested)

- **F1, final check on the program path:** run it only when the reply has no ANSWER line with a value; otherwise ship the decided reply. It removes the step that makes program splits and keeps its one useful job.
- **F2, `CHAIN_NOTE` reverts:** going back to the previous entry restores the value that held before the latest change.
- **F3, next-step answer line:** always person ; task ; channel, even when the question names only the owner and the channel; the channel as one word; ordinary words spelled correctly, also in the deciding call.
- **F4, status:** each state in the note's own word, spelled correctly.
- **F5, topic quantity:** read the traces first.
