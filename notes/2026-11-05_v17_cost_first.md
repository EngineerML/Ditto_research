# 2026-11-05: cost-first direction (bench v17 and screening policy v14), branches only

Peyton announced a cost-first incentive model on 2026-11-04, about 23:54 UTC. Nothing new is on `main`
(86934b6, v0.455.1). The work is on two ditto-subnet branches pushed the same evening.

## `ps/screener-v14-zero-call-permitted` (52fdaafa)

- `SCREENING_POLICY_VERSION` 13 → 14. The activation ceiling stays 13 until both screeners run 14 and the operator
  schedules it.
- **Behavioral oracle.** An agent with zero gateway calls now gets CLEAR ("behavioral-oracle-no-call-clear") instead
  of operator-review INCONCLUSIVE. An agent that does call but fails the token round-trip is still quarantined.
- **Runtime semantics.** A `no_model_call` result goes from fail to inconclusive.
- **Source review is unchanged.** The L2 policy tail for v14 is v13's, so I1–I8 still bind. The zero-call change is a
  runtime signal only. Whether a fully deterministic answer path squares with I4 (the deciding model writes the value)
  is not addressed.

## `ps/bench-v17-priced-cost-v2` (d08324e6)

- Bench 17 has the same dataset as v16 (datagen half from `profilesV16`, plus the generator slice); only the cost
  contract changes, to `priced-cost-v2`.
- The rates are still locked ($0.07/M prompt, $0.15/M completion). Cost is still normalised to a 350-case run.

| Contract | Reference cost | Factor at 1.5× reference | Floor | Floor reached at |
|---|---|---|---|---|
| v1 (v16) | $1.00 | 0.8 | 0.6 | $2.00 |
| v2 (v17) | **$0.50** | **0.65** | **0.3** | **$1.00** |

So in v17 the factor is 1 − 1.4·(cost − $0.50) for costs between $0.50 and $1.00, and 0.3 at $1.00 or more. A run with
zero model calls costs $0 and gets factor 1.0.
