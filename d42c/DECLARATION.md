### 0.4 What the host does with calls and replies

- The text that ships is a model completion: the host writes no reply text and edits none, apart from M22 and M24 (typography) and outer whitespace (§5).
- The deciding model sees the request's catalog after M74 on every turn, `tool_choice` `auto`, and decides every call; the host adds no call. It does not send a call whose arguments are unreadable, a call to a tool not offered (M74), or one with under 2 s left (M14); a call off its schema (M12) or with identifiers this user's store does not hold (M9) is answered with a note the first time and goes out when the deciding model sends the same call again (`app/action.py:736-741`); a call identical to one that already ran in this request, or whose delivery is unknown, is answered with a note the first time, and the same call sent again after that note is posted (M1); no separate check decides whether a call goes out; each unsent call is logged `blocked_before_execution` with a note as its result (§5).
- A stage is asked again only in these declared cases: an empty reply (one nudge), a reply cut at the length limit (once more at `low`, M18, M89) or a provider schema refusal (re-asked up to twice) (M5); a closing turn when the loop ends with no text (R4, A2); FQ's follow-up note (M32), armed by the request's shape; the advisory checks RC (M35), FC (M36), DR (M50), AK (M65) and CC (M68), each at most once per deciding loop, each ending with the deciding model's own next reply. After any of these notes the earlier reply ships only when the next one is empty.
- Routed text is limited to advisory notes and fixed prompt constants, picked by the request's words, the listed tools' names or the words of the user's own records (I5 clarification of 2026-10-23).

## 2. Served path

### 2.1 Entry

- `Dockerfile:8` starts `app.main:app`, one worker. `POST /seed` stores the user's pairs, subjects and links and embeds the pairs (M20; `app/main.py:46-58`). `POST /run` calls `CaseRunner.run` (`app/main.py:60-72`); an invalid body gets 400, a failed run 500, with the error text; bodies are ASCII JSON.
- SQLite store; every pair, subject, link and vector row is keyed by the user id (`app/store.py:11-51`). Its full-text index holds each pair's text with markup tags such as `<code>` masked as one neutral token, so a tag's name never matches a searched word and each record keeps its length; the pair itself is stored, searched for and shown as written (`app/store.py:26-34`, `app/store.py:56-60`, `app/store.py:85`). Of the request the host reads the case id, `system_prompt`, the message, the catalog, the tool endpoint, the user id and the relay URL (`app/protocol.py:25-32`); before any other step M74 drops the tools of apps the request does not name (`app/agent.py:115`); the case id goes only into tool endpoint bodies (`app/tools.py:143`) and logs. 285 s case deadline, one tool executor per case (`app/agent.py:117-121`).

### 2.2 Lane

Without a model the host ranks the user's stored conversations (`app/memory/retrieval.py:345-444`), finds the identifier focus (M7) and the request kinds (M52), and classifies the main clause (M44) with the catalog's tool names (M4) (`app/agent.py:124-132`). The first rule that holds moves an action-lane request to the records lane (`app/agent.py:133-144`):

|---|---|

| `identifier-held` | an identifier focus, and AT with its fetching test read per sentence |
| `own-records` | reason `live`; asks, names nothing to be done, no outside source, no capitalised name the store lacks; a name, address, code or quoted phrase of it, or the noun of "my/our <noun>", is in the store (`app/lane.py:370-414`) |

A records-lane request with a kind is decided on the action lane, reason `guided` (M53, `app/agent.py:145-146`). The lane picks prompt and packet; every turn that may call tools gets the whole catalog (M3).

## 5. Fixed properties

- `final_text` and `answer` are model text, outer whitespace removed, M22 and M24 applied; nothing else is written, cut, joined or re-worded.
- No reply is chosen among others by what it says. A stage is asked again only in the cases of §0.4 (M5, M18, M32, M35, M36, M50, M65, M68, M89).
